\subsection{Training and fine tuning for vocal removal}%
\label{sub:uvr}

Ultimate vocal remover (\url{https://ultimatevocalremover.com/}, \url{https://github.com/Anjok07/ultimatevocalremovergui/releases/tag/v5.6}) allows to remove the vocals from an audio file (this is sometimes useful in the music production world). In this context, the word "stem" stands for a main part in a song like the vocals, the drums, the bass, the synthetisers, etc.

The GUI allows to choose between various available pretrained models, notably:
\begin{itemize}
    \item[VR architecture] CNN, the oldest model in the app. Mostly for separation in 2 stems.
    \item[MDX-Net] Mostly for separation in 2 stems.
    \item[demucs] Hybrid transformer, can be used for multi-stem separation.
\end{itemize}

We note that the UVR contains the \textbf{inference code}, but not the \textbf{training} code. In this task, we will explore training our own models and compare their output to the models that are already available in UVR.

\subsection{Compression of a model for Food 101 classification}%
\label{sub:food101}

The Food 101 dataset (\url{https://huggingface.co/datasets/ethz/food101}) is a classical classification dataset. Many models have already been trained in order to solve this problem. You objective is to find the smallest, lightest possible neural network model that keeps a score close to the networks that achieve optimal performance. Here, we are interested in \textbf{compressing} an already trained network, in order to \textbf{decrease the size in memory, number of parameters, and inference time}. To do so, many methods exist, such a quantization, distillation and other methods that you should explore. You are encouraged to read research articles and use methods extracted from those. Study the tradeoff between the amount of compression and the final test score, and illustrate this tradeoff with visualizations.

\subsection{Clustering on the Fashion MNIST dataset}
\label{sub:Clustering}

The Fashion MNIST dataset (\url{https://github.com/zalandoresearch/fashion-mnist}) contains $28 \times 28$ pictures of clothes, with labels (like "Dress", "Pullover", etc).

A labeled dataset is interesting to cluster, because we can then compare the clusters (learned in an unsupervised way) to the labels (that have not been used in training). This comparison can be done by using specific \textbf{scores}, like the Normalized Mutual Information (NMI) (\url{https://scikit-learn.org/stable/modules/generated/sklearn.metrics.normalized_mutual_info_score.html}), the Adjusted Rand Index (\url{https://scikit-learn.org/stable/modules/generated/sklearn.metrics.adjusted_rand_score.html}), and/or by producing and interpreting \textbf{visualizations}. Note that other scores also exist (\url{https://scikit-learn.org/stable/api/sklearn.metrics.html}).

Perform a clustering on the Fashion MNIST dataset. Discuss the important algorithmic details and research: for instance, the \textbf{metric} and optionally the \textbf{embedding(s)} and/or \textbf{dimensionality reduction} methods used. Again, it is very important to discuss and interpret the results obtained.
